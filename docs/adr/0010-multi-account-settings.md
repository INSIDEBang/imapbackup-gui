# 0010 - 多账户设置与批量备份

Status: accepted

界面设置从「单套连接配置」升级为「账户列表」：设置页新增「账户」分类集中维护每个账户的连接信息（名称、邮箱地址、收件服务器、SSL、端口、经 DPAPI 加密的密码），并新增「备份」分类存放全局唯一的备份保存位置；备份页改成「左侧账户列表 + 右侧账户备份详情」，详情里连接信息与备份位置是只读信息卡，唯一可编辑项是格式复选框（mbox/eml）与文件夹勾选。每个账户有独立的文件夹勾选、邮件列表与进度，左栏每行带一个复选框（全选/反选/清空批量开关），「备份所选」只跑勾上的账户、按列表顺序串行运行，任一账户失败不影响其余，停止则结束当前账户并跳过后续账户。设置文件版本 1 → 2，旧 `config` 节迁移成单元素 `accounts` 列表、`outdir` 变成 `backup_root`。

账户名称是纯显示名，账号目录名始终取邮箱地址（延续 ADR 0002），所以改名不会移动既有备份、不破坏增量判重。账户用创建时生成的稳定 id 做引用键（列表勾选、选中账户、批量顺序、事件分发），名称与邮箱地址都不适合做键：前者可改、后者可重复。

## Considered Options

- **每账户独立备份位置**：更灵活，但同一账号可能被备份到多个根目录，迁移与清理边界变复杂；且用户明确要求地址统一，放弃。
- **备份页保留连接输入框（就地编辑）**：改动更小，但连接设置会散落在两个页面；用户要求集中到设置页、备份页只读，放弃。
- **每账户一套详情控件（各建一套 Treeview/Notebook）**：切账户零重绘，但控件数量随账户数增长，列宽契约与日志页签要在多处同步；改为一套共享控件 + 每账户状态字典，切账户时按状态重绘（邮件行多时有一次重绘开销，与运行中逐行插入同量级），放弃前者。
- **邮件列表加一列「账号」**：批量时一表看全，但每个账户的详情本就独立，加列会牵动 ADR 0008 的五列列宽契约与迁移；放弃。
- **账户名称参与账号目录名**：与 ADR 0002 的存量备份目录冲突（改名即换目录、重下一遍）；放弃。
- **不做 v1 迁移、直接丢弃旧设置**：实现最省事，但存量用户会丢列宽、窗口状态与已保存的账号；放弃。

## Consequences

- 设置文件（`%LOCALAPPDATA%\imapbackup-gui\treeview-columns.json`，文件名保持不变）版本 2：`accounts`（列表）、`backup_root`（全局唯一）、`selected_account`；`columns`/`window`/`close_action` 三节与 v1 同形。读取时按节独立降级：`accounts` 非列表整节丢弃，单个账户缺 `id` 跳过该账户，其余字段类型不符回落默认值。
- 文件夹勾选按账户持久化（存 IMAP 文件夹名）；缺省或全部失效时默认仅 `INBOX`。重连前先把界面上的勾选收回账户记录，重建不丢改动。
- 连接快照（服务器、邮箱地址、密码密文）按账户保存；账户在设置页被保存后即刷新该账户的过期态，取值回到快照即恢复「已连接」。
- 每个账户的备份都以服务器此刻的文件夹清单为准（运行前自己 LIST 一次）：从没连接过的账户在批量里也能直接跑。
- 批量运行按左栏列表顺序串行；账户级失败只记该账户状态与运行日志，批量结束按前台/后台给一次总结（后台只弹气泡）。
- 左栏的勾选集合是纯界面态、不写进设置文件：新建与读入的账户默认勾上，删账户即摘掉；「备份所选」跑的是勾上且信息完整（地址/服务器/密码）的账户，一个都没勾时只提示。账户行的复选框与「点行切详情」是可分别命中的两个动作，所以行是自绘控件而不是 Listbox。
- 备份页详情页不再有任何输入框：连接信息与备份位置只读；密码不出现在备份页，只在设置页账户表单里维护。
