# 0002 - 备份根目录下按账号加一层

Status: accepted

mbox 与 eml 两种输出的根目录下都自动插入一层以邮箱账号命名的目录（`<备份根>/<账号>/...`，账号取 `--user` 原值经 Windows 消毒），延伸 ADR-0001 的 eml 布局。动机：同一备份根目录会被多个账号复用（尤其未来 GUI 多账号场景），没有账号层时不同账号的同名文件夹会互相混在一起。

## Considered Options

- 仅 eml 加层、mbox 保持平铺：两种输出结构不一致，放弃。
- 加 `--by-account` 开关而非默认开启：fork 尚未发布、无存量用户，开关只会让备份散落在两种结构里；测试期用户的既有备份做一次移动迁移即可，放弃开关方案。

## Consequences

- 增量判重是内容级的（读邮件 Message-Id，不依赖路径），因此迁移 = 把既有备份文件夹移动到 `<备份根>/<账号>/` 下即可无缝衔接，不会重下一封。
- 目录名来自用户输入，经 sanitize_segment 消毒；`@` 在 Windows 文件名中合法，保留。
