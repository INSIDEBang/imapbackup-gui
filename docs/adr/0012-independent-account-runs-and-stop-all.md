# ADR 0012：账户独立备份运行与「停止所有」

Status: accepted

取代 ADR 0011 中的运行编排部分（其连接预检串行、密码补录仍有效）。

## Context

ADR 0011 的运行模型是「一次批量运行」：点「备份所选」后预检、全部账户进同一个批次，
由单一批量线程在开头把每账户下载线程全部发起，全部 `join` 后投 `batch_done`；
停止是一个全局 `threading.Event`，一停全停，运行中「备份所选」按钮禁用。

多账户日常使用暴露三个问题：

1. 备份进行中发现漏勾了账户，只能等整批结束（或全停）再重跑；邮件持续增长，用户希望
   随时追加，在跑的账户不受影响。
2. 右下「停止」实际停掉所有账户，无法只中止当前看着的这一个；账户之间缺独立反馈
   （后台账户到没到统计/下载阶段、成功还是失败，必须切过去看）。
3. 备份进行中点退出会直接掐断线程，而核心写盘不是原子的（mbox 一封两次追加、
   eml 整文件写入），可能留下半截文件。

## Considered Options

- **保持全局停止 + 批次概念，仅做「追加批次」**：实现小，但两套批次的汇总、
  「批量结束」语义、气泡触发都会变复杂；单账户停止仍无解。
- **排队模型（勾选=待办，自动串/并行消化）**：表达力强，但需要队列 UI、并发数控制等
  一整套新概念，超出当下需求；且与「勾选是纯意愿、默认全勾」的既有模型冲突。
- **账户各自独立运行 + 时间窗冷却（采纳）**：去掉批次对象，账户是唯一的运行主体。

## Decision

### 运行模型：账户独立、可追加

- 每个账户有自己的协作停止信号（`threading.Event`）、自己的阶段
  （`connecting/scanning/backing/stopping/idle`）与自己的下载线程；核心
  `should_stop` 回调只读本账户信号，三处检查点（文件夹间隙、每封邮件前）不变。
- 「备份所选」在备份中始终可点：候选＝勾着 ∧ 空闲 ∧ 不在完成冷却窗 ∧ 凭证齐全；
  候选走原有串行预检（与活动下载并行、互不干扰），通过后各自启动。
- 不再有 `batch_done`/「整轮」对象；活动集合（阶段非 idle 的账户）空→非空时开新周期，
  周期记账供结束日志与后台汇总气泡；活动集合排空即本轮结束。

### 完成冷却＝绿勾显示窗，同一个常量

账户成功完成后进入 60 秒冷却（`DONE_COOLDOWN_S`），期间：

- 行尾显示绿勾，到期自动消失；
- 「备份所选」跳过它，避免「给新账户补跑」的几秒内重连重扫已完成账户；
- 60 秒后自动重新参与长期增量更新；
- 右下「开始备份」是显式单账户命令，绕过冷却，想立即更新就点它。

已停止显示灰方块 5 秒（`STOPPED_ICON_TTL_S`，停止是用户自己发起的，只需短反馈）；
失败红叉常驻到下次启动或取消勾选。取消勾选（撤掉备份意愿）立即清终态图标与冷却。

### 行尾状态图标

账户行名称后方固定图标槽（透明位图占位，名称不横跳）：统计中蓝放大镜（连接同图标）、
备份中绿下箭头、已停止灰方块、完成绿勾、失败红叉。图标静态不旋转——动画只留在按钮上，
避免多行同时刷帧。预检阶段不显示图标（预检弹窗已在反馈）。

### 两个停止入口

- 右下「停止」只停当前选中账户；右下开始/停止按钮与转圈文案（正在统计…/正在备份…/
  正在停止…）全部跟随选中账户，切到空闲账户时该账户的视图可正常编辑。
- 「停止所有」在「备份所选」正下方，满宽，仅当存在活动账户时出现，全部收尾后消失；
  按钮自身显示转圈，宽度恒定（满宽不随文案变）。托盘菜单「停止备份」等同停止所有。

### 备份中退出：二次确认 + 优雅停止

任一账户活动时，关闭按钮的「退出程序」与托盘退出都先弹自绘确认窗（取消为安全侧）；
确认后对所有活动账户发停止信号，轮询等它们写完当前封、干净收尾后落盘退出；
等待上限 15 秒（`QUIT_STOP_TIMEOUT_S`），超时记 warning 强制退出。确认窗在等待期转
「正在停止，等待 N 个账户收尾…」态。「隐藏到后台」不是退出，永不拦截；预检中退出不拦
（预检线程为 daemon 且不写盘）。

## Consequences

- 全局 `stop_flag`、`running/stopping` 整轮布尔、`_batch_worker`、`batch_done`、
  `account_skipped` 移除；`self.running` 保留为「存在活动账户」的派生属性。
- 配置区锁定从「任一账户在跑锁全局」收窄为「可见账户在跑锁可见视图」；后台账户下载
  不再冻结当前选中账户的文件夹勾选。
- 设置页禁止删除活动账户（弹警告），编辑仍允许（运行用的是开跑时快照）。
- 前台失败弹框只在失败账户正被看着时出现；其余账户失败只走红叉与状态行；后台仍按
  活动集合排空气泡一次。
- 核心写盘非原子的风险在退出路径被优雅停止覆盖；单封写一半时进程崩溃/强杀的边缘情况
  仍存在（与 ADR 0003 的协作停止粒度一致）。
