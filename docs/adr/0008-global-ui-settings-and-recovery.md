# 全局界面设置与应用数据恢复契约

Status: accepted

界面设置统一保存在 `%LOCALAPPDATA%\imapbackup-gui\` 的应用数据目录中，与按天保存的运行日志并列；它们按 Windows 用户全局生效，不按账号、邮箱文件夹或备份根目录分层。设置文件使用带版本号的通用 JSON，并兼容旧的仅列宽格式。本次保存邮件列表五列的全局列宽，以及主窗口正常状态的宽高、位置和最大化状态；不保存滚动位置、排序状态、密码、服务器凭据、会话令牌或邮件内容。窗口变窄或变宽时，五列均按比例缩放并遵守各自原生最小宽度。最大化时保留最大化前的正常几何，启动时先恢复正常几何再恢复最大化；跨显示器导致位置完全不可见时只回退位置并保留有效尺寸。这样同一用户在不同账号与文件夹之间能保持稳定的界面布局，同时避免把凭据写入本地配置文件。

## Considered Options

- **按账号或文件夹保存列宽**：能表达更细的个性化，但会让设置与账号目录、备份根目录绑定，增加迁移和清理边界；列宽是界面习惯而不是邮箱数据，否决。
- **保存凭据以便自动连接**：减少重复输入，但扩大泄露面，且 Windows GUI 没有本项目承诺的凭据保管边界；密码只在当前进程内存中存在，否决。
- **设置损坏或写入失败时阻止启动/备份**：能强制用户修复配置，但把非核心的界面状态变成备份前置条件；与只读备份和“日志不可用也不应阻止备份”的降级原则冲突，否决。
- **卸载时只提供一个整体删除选项**：交互简单，但无法保留日志或界面设置其中一类；不符合用户对应用数据清理粒度的要求，否决。
- **只保存关闭瞬间的最大化几何**：最大化后的几何不是用户下次恢复时想要的正常窗口尺寸，且不同显示器布局下不稳定；改为保存最大化前最后一次正常几何。

## Consequences

- 设置不存在、无法解析、字段类型不符或版本不兼容时，整份设置回退到内置默认值并继续运行 GUI；诊断信息进入运行日志，日志不可用时回落到现有 console/状态提示，不弹阻断式错误框。
- 写入失败时保留当前进程中的设置，继续允许界面操作、连接和备份；下一次启动使用上一次成功保存的设置或默认值。失败不得覆盖仍可读取的旧文件，也不得触碰备份输出。
- 窗口缩放导致总列宽与可视区域不一致时，按当前列宽比例调整各列，并保留各列的 Tk 原生最小宽度。
- 窗口状态只在关闭时写入；拖动或调整过程中只更新内存。正常几何和最大化状态字段独立校验，窗口状态无效不丢弃有效列宽。关闭时写入失败不阻止窗口销毁。
- 卸载向导分别提供“删除运行日志”和“删除界面设置”选项，默认均勾选；取消向导或中途取消进度时两者均保留，确认删除或默认静默卸载时按各自选项清理。用户备份目录始终不在范围内（与 ADR 0007 共同构成卸载契约）。
